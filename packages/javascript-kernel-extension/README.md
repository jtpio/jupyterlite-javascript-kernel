# @jupyterlite/javascript-kernel-extension

The JupyterLite extension registering the JavaScript kernels, `javascript`
(`JavaScript (IFrame)`) and `javascript-worker` (`JavaScript (Web Worker)`),
with their settings.

It is a prebuilt extension: install it in a JupyterLite site with the
[`jupyterlite-javascript-kernel`](https://pypi.org/project/jupyterlite-javascript-kernel/)
Python package, not from npm. See the
[README of the repository](https://github.com/jupyterlite/javascript-kernel#readme).
